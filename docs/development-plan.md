# Find the White Rabbit — 开发执行清单

> 这是开发顺序；开始编码前先完成策展与视觉确认。

## 第一轮：策展与资产

- [ ] 汇总 Instagram 导出的全部可用照片，保留原文件名。
- [ ] 标记不可公开、分辨率过低或不属于系列的图片。
- [ ] 按情绪而不是拍摄日期排出 8–20 件候选顺序。
- [ ] 为每张候选图写客观 alt、标题、地点、年份和一句展签。
- [ ] 确认首件、末件，以及当前通道图是否为 `Approach / 靠近`。

## 第二轮：视觉定稿

- [ ] 用最暗、最亮、最竖、最横、首件五张照片校准画框尺度。
- [ ] 确定桌面、平板、手机上的展签位置。
- [ ] 确认白兔为极简白色轮廓/耳朵，不使用 Emoji 或卡通兔。
- [ ] 出齐四个状态：观看、兔子出现、Dock 展开、About。
- [ ] 摄影师确认首屏留白、图片大小、字排后，再开始交互实现。

## 第三轮：确认后编码

- [ ] 初始化 Next.js + TypeScript + pnpm。
- [ ] 放入优化后的本地资产和作品数据。
- [ ] 先做不含兔子的静态单件页面，并在真实浏览器审阅。
- [ ] 逐步加入状态机、兔子、作品切换、Dock、About。
- [ ] 完成桌面/手机录屏、键盘、触控与减少动态效果验证。

## 发布前

- [ ] 图片公开授权与署名信息已确认。
- [ ] 正式图片源不使用 Instagram 嵌入或第三方外链。
- [ ] 首屏、兔子、Dock、About、末件和 Restart 已分别录屏验收。
- [ ] 预览链接经摄影师确认后再绑定正式域名。
