# Follow the white rabbit

> “地铁经过城市，也经过许多没有被说出口的时刻。  
> 屏幕发亮，车门打开又关闭；有人独自醒着，有人把头靠在另一个人肩上。  
> 这些照片没有终点。请停下来，等待那只白兔出现。”

---

## 展览简介 · Exhibition Note

这是一场关于城市通勤、陌生人与微小相遇的线上沉浸式摄影展。

在信息过载与快速滑屏的当下，展厅剥离了所有常驻导航条、翻页按钮与数字计数。每一位观众都是这趟列车上的同行者——唯有停下来、驻留凝视，作为向导的那只白兔才会悄然现身，指引你走向下一处陌生人的光影与故事。

---

## 观展旅程 · The Journey

展览由两个阶段构成：**单向沉浸探索** 与 **完展解锁后的环形回望**。

```text
【初次探索：单向凝视】
  序言展签 (Exhibition Note) 
     ↓ 点击「开始观看 ↗」
  照片入场 → 凝视驻留 (2s) → 边缘随机等待 → 白兔探头
     ↓ 点击白兔（逐张前行，共 14 站）
  手写 END 画框
     ↓ 完展解锁（当前会话记忆）

【回望重温：时空胶囊】
  底部浮现微型呼吸光点
     ↓ 点击光点
  3D 弧形卡片画廊 ↔ 自由重访任意作品（白兔立现，随时穿梭）
```

### 1. 序言 · 启程
展厅始于一幅素雅的展签画框。轻触「开始观看」，列车正式启程，将喧嚣关在门外。

### 2. 凝视 · 寻觅白兔
- **驻留**：每幅作品入场后保持绝对静止，请给眼前的陌生面孔片刻凝视。
- **偶遇**：白兔在相框边缘不经意探头——有时趴在相框内侧，有时双爪搭着框沿。
- **引路**：轻触白兔，它便悄然隐去，引领你进入下一个车厢时刻。

### 3. 终章 · 手写 END
走过全部 14 处车厢光影后，抵达一幅带有笔触温度的手写 **END** 画框。一次完整的凝视旅程在此告一段落。

### 4. 回望 · 呼吸光点与环形画廊
- 完整走完全程的观众，屏幕底部会悄然解锁一颗**微微悬浮、循环呼吸发光的微型圆点**。
- 轻触圆点，14 幅作品将如环形全景画廊般在视线中拱形展开，两侧向后隐退，支持随心拖拽滑动。
- 在回看模式中，白兔将静候在相框边缘，免去等待，随时陪伴重温每一个瞬间。
