# 序言、照片与 END — 开发记录

## 已确认的设计

用户经 grilling 讨论确认：用序言画框替代导航与 About 弹窗，点击开始观看后跟随画框四周的兔子顺序看照片，末张兔子通向手写 END，进入 END 才解锁底部目录。无重播按钮；同标签页刷新保留目录解锁。移除根据系统减少动态效果偏好切换 Next 的机制。

完整规则见 [已确认实施规格](approved-exhibition-spec.md)。

## 实现范围

- 状态机新增 INTRO 与图片加载阶段；末张遵循相同等待流程，点击兔子后进入 END 并标记完成。
- 当前标签页用 sessionStorage 保存完成状态；没有存储权限时退回内存状态。
- 序言、照片与 END 共享画框语言；手写 END 使用本地 SVG 笔画，不依赖远程字体。
- 兔子相对画框定位，手机侧边位置转到上下安全边；同一张照片不自行跳动。
- 完成后目录可直接选照片，回看立即提供兔子；支持模态键盘焦点管理。
- 顶部导航、About 弹窗、结束按钮、Restart、reduced-motion Next 分支移除。
- 保留已有作品目录视觉、媒体路径、照片次序与本地未提交的其他工作。

## 2026-09-20 相框内侧调整

按用户截图反馈，将兔子由框外探出改为趴在框内：四条边统一向内定位，兔子层级位于相框上方，尺寸上限随画框收缩。保留现有兔子素材、随机安全边和观看节奏。旧的框外截图验收不代表本次内侧效果已验收。

## 2026-09-20 缩短首遍等待

按用户确认，将节奏调整为入场 500ms、驻足 2 秒、随机等待 500–1000ms、点击离场 200ms。加载完成后 3–3.5 秒开始出现兔子，末张同样适用；回看仍不强制等待。同步 CSS 动画与状态机计时。

## 2026-09-20 顶部趴框姿态

顶部作为内侧定位的例外：爪子搭住相框上沿，头与耳朵露在框外。通过 CSS 裁去顶部素材下半部的透明留白，让可点击范围跟随头和爪子，并使用按比例偏移适配桌面与手机。其他三边与观看节奏保持不变。

## 2026-09-20 悬浮光点与环形画廊

圆圈加入 5px 上下浮动及暖白呼吸光晕。目录独立为 GalleryDock 组件，使用有透视深度的环形布局，中央突出，两侧沿弧线下沉；支持首尾循环、左右按钮、键盘方向键和水平拖动/手机滑动。保留看完才解锁、点击照片观看与模态焦点规则；拖动后不误触照片。

23 项自动测试、Lint、类型检查及生产构建通过，`git diff --check` 通过。更新后的生产预览已在 http://127.0.0.1:3101 启动。浏览器当前停留在用户的其他页面，为避免打断使用未继续切换；本次环形布局、光晕及手机触控的最终视觉验收仍待完成。
