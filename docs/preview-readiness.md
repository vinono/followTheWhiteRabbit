## 2. 跨端视觉与交互验收矩阵 (Verification Matrix)

在桌面（宽屏 Chrome/Safari）与移动端（iOS Safari/Android Chrome）真实审阅以下链路：

| 验证项 | 验证内容与预期结果 |
| :--- | :--- |
| 序言 | 首屏画框展示标题、原说明、开始观看；不启动兔子计时 |
| 首遍 | 图片加载后入场 0.5s，再驻足 2s、随机等待 0.5–1s，点击兔子离场 200ms 后到下一张 |
| 画框安全边 | 左、右、下方兔子位于相框内侧；顶部兔子爪搭上沿、头和耳朵露在框外；窄屏优先上下边 |
| 统一路径 | 系统 motion 偏好不隐藏兔子，不出现 Next；键盘和触控可完成 |
| 末张与 END | 末张同样等待兔子；点击后才进入手写 END 并解锁底部圆圈 |
| 作品目录 | 首遍未完成时不可用；完成后圆圈悬浮发光，点击出现拱形环状画廊；14 张首尾循环，拖动/左右键可浏览，选择照片后关闭 |
| 目录交互 | Esc、关闭按钮、外部遮罩均可关闭；模态约束焦点，照片背景不可交互 |
| 刷新 | 同标签页回到序言，完成记录和圆圈保留；独立新访问不解锁 |
| 手机 | 序言自然滚动，照片不裁切，兔子不溢出屏幕，圆圈点击区域至少 44×44px |

本矩阵按 [2026-09-19 确认规格](approved-exhibition-spec.md) 更新。当前验证证据见 [开发记录](exhibition-redesign-2026-09-19.md)，上述表格定义预期，不代表所有设备已经验收。

## 3. Link-Only Preview 发布配置规范

1. **防爬虫与不公开索引**：
   - `app/layout.tsx` 中已严格配置 `robots: { index: false, follow: false }`；
   - 生产部署环境（如 Vercel / Cloudflare Pages）请勿绑定根域名，仅使用平台生成的随机预览二级域名。
2. **云存储 CDN 对接**：
   - 将这 14 张优化后的 JPEG 衍生图上传至 Cloudflare R2、AWS S3 或阿里云 OSS 对应路径（如 `201807/17940891781080539.jpg` 等）；
   - 在部署环境变量中注入 `NEXT_PUBLIC_MEDIA_BASE_URL=https://<your-cdn-domain>`；
   - 原始大图与 RAW 文件严禁上传至公开 Bucket。
3. **摄影师终审前流程**：
   - 部署完成后将预览链接发送给摄影师/策展人；
   - 摄影师在手机与电脑上审阅完毕并确认无误后，方可解除 `robots` 限制并绑定主域名正式发布。
